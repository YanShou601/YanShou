# 研寿笔记

别人这么做，我们就这么做。

Bryan Johnson 每年 200 万美元医疗团队分析出来的方案，以及其他成功案例的实践，就是我们的策略来源。我们的工作是跟随、采纳、落地，不是用 AI 爬公开数据去质疑。

## 目录

- catalog/supplements.csv：全部补剂候选及状态。
- catalog/products.csv：具体产品、市场版本与产品质量。
- dossiers/：补剂策略档案——怎么用、买什么、谁在用。
- cases/：人物案例——他们具体怎么做。
- products/：品牌梯队与购买指南。
- papers/：论文记录。
- sources/：来源清单。
- methods/：工作规范。
- esearch-log/：研究日志。
- 	emplates/：模板。

## 档案写法

- 开头写"Bryan Johnson 怎么用"或案例人物怎么用；
- 品牌和服用方式直接给出；
- 保留基本安全提示（药物相互作用、特殊人群）；
- **不说**"没有延寿证据""人体证据不足""不能证明有效""等待独立重复"。

## 产品质量

- P1–P3 帮助选择具体产品；
- 评的是具体 SKU，不是整家公司。
