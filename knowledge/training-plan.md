# 个人训练计划

## 每次训练前

- **跑步机热身**：4 倍速，快速走 20 分钟

## 三天循环

### 第一天：胸 + 三头

| 动作 | 部位 |
|---|---|
| 哑铃卧推 | 胸 |
| 上斜哑铃推胸 | 胸（上胸） |
| 哑铃飞鸟 | 胸 |
| 俯身臂屈伸 | 三头 |
| 哑铃颈后臂屈伸 | 三头 |
| 哑铃窄握卧推 | 三头 |

### 第二天：背 + 二头

| 动作 | 部位 |
|---|---|
| 哑铃正手划船 | 背 |
| 哑铃反手划船 | 背 |
| 哑铃单手划船 | 背 |
| 哑铃弯举 | 二头 |
| 锤式弯举 | 二头 |
| 哑铃集中弯举 | 二头 |

### 第三天：肩 + 腿

| 动作 | 部位 |
|---|---|
| 哑铃推举 | 肩 |
| 侧平举 | 肩（中束） |
| 俯身飞鸟 | 肩（后束） |
| 哑铃深蹲 | 腿 |
| 哑铃硬拉 | 腿 / 后链 |
| 箭步蹲 | 腿 |

### 核心 + 腹部（隔天练，暂未开始）

| 动作 | 组数 × 次数 |
|---|---|
| 卷腹 | 3 组 × 15–20 次 |
| 仰卧举腿 | 3 组 × 10–15 次 |
| 平板支撑 | 3 组 × 60 秒 |
| 俄罗斯转体 | 3 组 × 20 次（左右各 10） |

## 补剂配合

结合 Bryan Johnson 方案，训练日每天补充：

- **肌酸**：5 g 肌酸一水合物（Thorne 或 NOW Foods），每天吃，训练日和休息日都吃
- **蛋白质**：训练后确保蛋白质摄入充足
- **镁**：100–200 mg 元素镁（甘氨酸镁），晚上服用，有助恢复
