# Andrew Huberman 的方案

Andrew Huberman，斯坦福医学院神经生物学与眼科学教授，Huberman Lab 播客主理人。他的定位是**用神经科学做"可执行的工具/协议"**，核心信条是：零成本工具（光照、睡眠、运动、呼吸）先做到位，补剂只是"最后的 5%"。

::: tip 本项目怎么用这份资料
Huberman 是有学术背景的权威方案，本项目**直接采纳**其做法，不做疗效评审。下面剂量均为其公开播客/官网提到的常见用量，未逐条归档一手来源，标 `needs-source-check`。**他的补剂推荐与商业利益绑定度高**，合作关系已重点披露，不影响采纳，但读时要心里有数。
:::

## 核心理念

- **零成本工具优先**：光照、睡眠、运动、呼吸、社交/关系、压力管理是地基；补剂是锦上添花。
- **协议化思维**：把行为拆成可重复的"协议"，按时段执行。
- **神经可塑性 + 昼夜节律**：很多工具的本质是在正确时间给大脑正确信号。

## 光照协议（他最标志性的零成本工具）

| 时段 | 做法 |
|---|---|
| 起床后 30–60 分钟内 | 户外自然光 2–10 分钟（阴天/清晨更久），设昼夜节律、提振情绪 |
| 傍晚 | 看夕阳/低角度光，给"日落信号" |
| 夜间 | 避顶光/强光，用暖光/红光，护褪黑素 |

## 补剂协议（分"栈"，按时段）

### 基础 / 白天栈

| 补剂 | 其公开常见用量 | 说明 |
|---|---|---|
| 维生素 D3 + K2 | 按体重/检测，常 1000–4000 IU | 随含脂肪餐 |
| Omega-3 | 重 EPA，约 1000–2000 mg EPA/天 | |
| 镁 | 苏糖酸镁或甘氨酸镁 | 也可挪到睡眠栈 |
| 肌酸 | 5 g/天，推荐几乎所有人 | |
| 电解质（钠/钾/镁） | 训练/桑拿/晨起按需 | |

### 睡眠栈（睡前 30–60 分钟，"睡眠鸡尾酒"）

| 补剂 | 其公开常见用量 | 说明 |
|---|---|---|
| 镁（苏糖酸镁/甘氨酸镁） | 约 145 mg 元素镁（threonate）或 100–150 mg（glycinate） | |
| 芹菜素（apigenin） | 50 mg | |
| L-茶氨酸（theanine） | 100–400 mg | |

> 他强调这套对多数人有效，但**非人人需要、可轮换**，不是必须每天全上。

### 专注栈（按需，不每天）

咖啡因 + L-茶氨酸、或 α-GPC、或 L-酪氨酸等。他反复强调**按需、别每天堆**，警惕耐受与依赖。

::: warning 与 Bryan 的分歧（如实记录）
Huberman 对 **NMN/NR** 讨论过机制但偏**谨慎/观望**，没有放进基础栈；Bryan 在用 NR/NMN。本项目把两种取舍都记下，不对 NMN 做疗效否定。
:::

## 训练

- 周结构覆盖**力量 + 有氧 + 灵活性**；常见框架为每周 2–3 次力量 + Zone 2 + 一次 HIIT/VO2max 类。
- 重视**运动时机与昼夜节律**、训练后冷水/桑拿。
- 推崇 **NSDR / 瑜伽 nidra**（non-sleep deep rest）10–30 分钟做恢复与减压。

## 睡眠

- 固定作息、降温、避光、睡前流程；与 Attia 一样视睡眠为修复核心。
- 用 NSDR/瑜伽 nidra 在白天补恢复、降压力。

## 一天大致节奏（公开内容归纳）

```
晨起   户外光照 2–10 分钟 + 水/电解质 + 延迟咖啡因 90–120 分钟
上午   基础栈随早餐（D3+K2、Omega-3、肌酸）
训练   力量/有氧/灵活 轮换；练后冷水或桑拿
白天   专注栈按需；NSDR 10–30 分钟补恢复
傍晚   看夕阳；转暖光
睡前   睡眠栈（镁 + 芹菜素 + 茶氨酸），降温避光，固定时间入睡
```
