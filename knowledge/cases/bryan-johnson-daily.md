# Bryan Johnson 的一天与一周

Bryan Johnson，1977 年生，企业家（Braintree/Venmo 创始人，2013 年以 8 亿美元卖给 PayPal）。2021 年启动 Project Blueprint，每年投入约 200 万美元，由专业医疗团队（ بقيادة Oliver Zolman 医生）分析、检测、调整方案。他是目前公开记录中**被生物测量最多的人**。

## 他的一天

### 05:00 — 起床

- 自然醒，不用闹钟（睡眠周期规律后身体自动醒）
- 起床后立刻接受**光照**（自然阳光或光疗灯），校准昼夜节律

### 05:00–05:30 — 清晨补剂（空腹）

所有补剂集中在早上一次性服用：

| 补剂 | 用量 | 说明 |
|---|---|---|
| Blueprint Longevity Mix | 1 勺 | 复方，含多种活性成分 |
| 肌酸（Creatine） | 额外 5 g（Mix 中另含 2.5 g，总计 ~7.5 g） | 力量与肌肉 |
| 益生元纤维 | 半茶匙 GOS + 1 茶匙菊粉 + 1 茶匙阿拉伯半乳聚糖 | 肠道菌群 |
| Blueprint Collagen Peptides | 11 g | 皮肤、关节 |
| Blueprint Essential Capsules | 2 粒 | 含维生素 D3、镁、B 族等 |
| Blueprint Advanced Antioxidants | 1 粒 | 抗氧化复方 |
| Ashwagandha + Rhodiola | 1 粒 | 适应原，压力管理 |
| Omega-3 | EPA 400 mg + DHA 400 mg（藻油） | 心血管、大脑 |
| Proferrin（铁） | 10.5 mg | 铁补充 |
| NR 或 NMN | NR 450 mg 或 NMN 500 mg（二选一） | NAD⁺ 前体 |

### 05:30–07:00 — 训练（60–90 分钟）

Bryan 的训练不是单纯举铁，而是**四种能力全覆盖**：

| 类型 | 内容 | 频率 |
|---|---|---|
| **力量** | 复合动作为主（深蹲、硬拉、推举、划船等） | 每天 |
| **有氧** | 跑步、骑车、游泳等 | 每天 |
| **柔韧性** | 拉伸、瑜伽动作 | 每天 |
| **平衡** | 单腿站立、平衡板等 | 每天 |

每周总训练量约 **6 小时**。

### 07:00–12:00 — 进食窗口（所有热量在此完成）

Bryan 的哲学：**"每一卡路里都必须为它的存在而战"**（Every calorie must fight for its life）。

他每天约 **2,250 kcal**，蛋白质约 **130 g**，全部在早上到中午之间吃完。

**典型三餐：**

| 餐次 | 时间 | 内容 |
|---|---|---|
| 第一餐 | ~07:00 | **Super Veggie**：西兰花、花椰菜、蘑菇、大蒜、生姜、橄榄油等蔬菜组合 |
| 第二餐 | ~09:00 | **Nutty Pudding**：澳洲坚果奶、蓝莓、覆盆子、奇亚籽、肉桂等 |
| 第三餐 | ~11:00 | 植物为主的正餐：豆类、全谷物、蔬菜、坚果 |

饮食特点：
- **几乎全植物性**（唯一例外是胶原蛋白肽）
- 不吃加工食品、精制糖、油炸食品
- 不喝咖啡（下午 2 点后任何咖啡因都不碰）
- 不喝酒
- 每餐营养密度极高，"不让大脑替你做吃的决定"

### 12:00 — 最后一餐结束

**中午之后不再进食。** 这是 Bryan 方案的核心之一。

他的原话：
> "我中午左右停止进食，到睡前静息心率会降到约 39 次/分。如果我在睡前 1 小时吃了东西，心率会到 56，睡眠质量会差 30–40%。"

### 12:00–17:00 — 工作

- 管理 Blueprint 公司
- 审阅生物标志物数据
- 与医疗团队沟通方案调整
- 内容创作（YouTube、X/Twitter）

### 17:00–21:00 — 晚间（不进食）

- **下午 5 点后不吵架**（"No fights after 5 pm"——精力留给早上）
- 散步、阅读、陪伴家人
- 晚上使用**红光和琥珀色灯光**，避免蓝光
- 手机开启夜间模式 / 使用 f.lux 等蓝光过滤软件

### 21:00–21:30 — 睡前流程

- **睡前 60 分钟关闭所有屏幕**
- 睡前 10 分钟读书
- 可以做：冥想、呼吸练习、写日记、听播客
- 卧室保持**凉爽、完全黑暗**

### 21:30–22:00 — 入睡

- 目标睡眠时间：~22:00
- 目标睡眠时长：**8 小时**
- Bryan 曾连续 **8 个月可穿戴设备记录 100% 完美睡眠**

### 他的睡眠规则（原话总结）

| 规则 | 说明 |
|---|---|
| 睡前 4 小时不进食 | 他实际是睡前 ~10 小时（中午停食） |
| 睡前 60 分钟关屏幕 | 蓝光抑制褪黑素 |
| 下午 2 点后不喝咖啡 | 咖啡因半衰期 6 小时 |
| 晚上用红光/琥珀光 | 保护褪黑素分泌 |
| 下午 5 点后不吵架 | 避免皮质醇升高影响入睡 |
| 卧室凉爽、黑暗 | 核心体温下降有助入睡 |
| 睡前 10 分钟读书 | 让大脑安静下来 |
| 睡眠是第一优先 | "高质量睡眠是世界上排名第一的长寿药" |

## "晚间 Bryan"理论

Bryan 提出了一个很实用的心理框架：

> "晚间 Bryan，你被解雇了。你让我的生活很 miserable。我睡不着，超重 60 磅，感觉糟透了。"

他把自己不同时段的状态分成不同"人格"：
- **晚间 Bryan**：冲动、想吃垃圾食品、缺乏自控 → **被剥夺了下午 5 点到 10 点之间吃东西的权力**
- **睡眠 Bryan**：需要安静、凉爽、黑暗的环境
- **早晨 Bryan**：精力充沛、做出理性决策
- **工作 Bryan**：专注、高效
- **爸爸 Bryan**：陪伴孩子

核心思想：**不要让最差状态下的自己替最好的自己做决定。**

## 训练详情

### 每周训练结构

| 类型 | 时间 | 说明 |
|---|---|---|
| Zone 2 有氧 | ~150 分钟/周 | 可以正常说话的强度（快走、骑车、游泳） |
| 高强度间歇（HIIT） | ~75 分钟/周 | 无法说话的强度 |
| 力量训练 | 每天 | 复合动作为主 |
| 柔韧性 | 每天 | 拉伸、瑜伽动作 |
| 平衡 | 每天 | 单腿站立、平衡板 |

### 训练原则

1. **避免受伤**——受伤比不练更糟糕，宁可保守
2. **每天练，不给自己选择权**——像刷牙一样成为习惯
3. **四种能力全覆盖**——力量、有氧、柔韧、平衡缺一不可
4. **每餐后活动 5–10 分钟**——每坐 30 分钟就起来动一动
5. 每周总计约 **6 小时**

### 典型训练动作（公开视频和协议中出现过的）

**力量：**
- 深蹲（Squat）
- 硬拉（Deadlift）
- 卧推 / 哑铃推胸
- 划船（杠铃 / 哑铃）
- 肩推
- 引体向上 / 下拉
- 弓步蹲
- 平板支撑及变体

**有氧：**
- 跑步（Zone 2 为主）
- 骑车
- 游泳
- 快走

**柔韧 + 平衡：**
- 各种静态和动态拉伸
- 单腿站立
- 瑜伽动作
- 泡沫轴放松
