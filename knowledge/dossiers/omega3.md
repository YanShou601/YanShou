# DHA / EPA

::: tip 30 秒结论
DHA 和 EPA 是两种长链 Omega-3 脂肪酸。DHA 是脑和视网膜细胞膜的重要组成部分，EPA 更常被讨论其炎症介质和血脂作用。**吃鱼与吞鱼油不是一回事**：一般健康人补普通鱼油并没有稳定证明可以预防心血管事件，高甘油三酯或特定高风险人群使用的处方级产品需要单独评价。
:::

| 快速判断 | 当前答案 |
|---|---|
| 它是什么 | 细胞膜和信号分子所需的长链脂肪酸 |
| 为什么受关注 | 心血管、脑、视网膜和炎症相关生理作用 |
| 人体证明了什么 | 可降低甘油三酯；部分处方级方案在特定人群有临床证据 |
| 能不能延寿 | Bryan Johnson 当前方案采用 |
| 食物还是补剂 | 优先富脂鱼类；不吃鱼者可研究藻油等替代来源 |
| 当前等级 | **T1，但必须限定人群、配方与目标** |

## 先说人话：它在身体里做什么？

可以把细胞膜想成细胞的“外壳和控制面板”。DHA、EPA 会进入这层膜，并参与产生不同的信号分子。DHA 在脑和视网膜中尤其丰富；EPA/DHA 也能降低肝脏输出的甘油三酯。但“参与重要生理过程”并不等于摄入越多越好，更不等于所有鱼油胶囊都能预防心梗。

## 从哪些食物获得？

- 三文鱼、沙丁鱼、鲭鱼、鳟鱼、鲱鱼等富脂鱼；
- 贝类也可提供一部分；
- 藻类是 DHA/EPA 的原始来源之一，藻油可作为不吃鱼人群的产品形式；
- 亚麻籽、奇亚籽和核桃主要提供 ALA，人体转化为 EPA/DHA 的比例有限，不能简单按同等剂量替换。

## 补剂怎么选、怎么看标签？

- 看每份实际 **EPA + DHA** 含量，不看“鱼油 1000 mg”总重量；
- EPA 单方、EPA+DHA 复方和藻油不能混为同一证据；
- 高甘油三酯治疗剂量和普通保健剂量是不同问题；
- 注意第三方质量检测、氧化异味和保存条件；
- 高剂量与房颤、出血风险需要结合个人病史和药物评估。

## 编辑结论

研究量大，但不能概括为“人人都应长期补鱼油”。配方、剂量、膳食鱼类摄入、甘油三酯、既往心血管病以及是否为处方级 EPA 都会改变结论。

## 适用条件

- 先评估每周鱼类摄入；
- 将一般人群一级预防、已有冠心病和高甘油三酯分开；
- EPA 单方不能与 EPA＋DHA 复方合并解释；
- 普通保健鱼油不能替代处方制剂。

## 安全边界

高剂量下需关注房颤和出血相关信号。房颤、抗凝药、术前或出血风险人群应先咨询医生。
