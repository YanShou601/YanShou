# 镁

::: tip 30 秒结论
镁像身体里数百种酶的“辅助工具”，参与能量代谢、神经传导、肌肉收缩和心律。明确不足时补充有意义；但睡不好、抽筋、疲劳并不自动等于缺镁。人体试验中补镁对血压的平均改善较小，较明显的效果多见于低镁或高血压人群。**先看饮食和风险因素，再决定是否需要补剂。**
:::

| 快速判断 | 当前答案 |
|---|---|
| 它是什么 | 必需矿物质和多种酶反应的辅助因子 |
| 为什么受关注 | 能量、神经、肌肉、心律和血压都需要它 |
| 人体证明了什么 | 纠正不足有意义；部分人群血压或偏头痛可能获益 |
| 能不能延寿 | 没有证明健康人补镁可延寿 |
| 食物还是补剂 | 优先豆类、坚果种子、全谷物和绿叶菜 |
| 当前等级 | **T2：条件性使用** |

## 先说人话：它在身体里做什么？

酶就像身体里的微型机器，很多机器需要镁离子才能稳定工作。它也参与神经信号、肌肉收缩与放松。问题是这些作用太广泛，容易让任何模糊症状都被营销成“缺镁”。真正判断时要同时看饮食、疾病、药物、肾功能和临床表现，而不是只凭一种感觉。

## 从哪些食物获得？

- 南瓜籽、奇亚籽、杏仁、腰果等坚果种子；
- 豆类、豆制品；
- 菠菜等绿叶蔬菜；
- 全谷物；
- 部分矿泉水也能提供镁。

## 补剂怎么选、怎么看标签？

- 看标签中的**元素镁**，不是整种化合物的重量；
- 柠檬酸镁、氯化镁等通常比氧化镁更易吸收，但前者也可能引起腹泻；
- 选择哪种盐型要看目的和耐受性，不能仅凭“吸收率排名”；
- 成人每日 350 mg 的 UL 只计算补充剂和药物来源，不包括天然食物中的镁。

## 编辑结论

镁是必需矿物质，纠正明确不足或处理特定适应证有价值；这不等于所有健康人都应长期服用镁片。一般健康人因单纯膳食摄入低而出现有症状缺乏并不常见，而且血清镁不能很好代表全身储量。随机试验综合显示补镁对血压的平均影响较小，较明显的效应主要出现在高血压、正在用降压药或低镁亚组。因此把镁列为“有条件使用”的 T2，比列为人人必备更符合证据。

## 研究问题

- 人群：缺乏或不足风险人群、高血压患者、偏头痛患者与一般健康人分开；
- 干预：按“元素镁”剂量记录，并区分具体盐型；
- 对照：安慰剂、饮食改善或标准治疗；
- 主要结局：症状、血压、偏头痛频率、临床事件与不良反应；
- 不把单次血清镁正常直接解释为储量一定充足。

## 可能获益

- 纠正胃肠道疾病、长期大量饮酒、部分药物或肾脏丢失相关的镁不足；
- 高血压或低镁人群中可能小幅降低血压；
- 偏头痛预防存在一定指南支持，但常用剂量可能超过补充剂 UL，应在医疗专业人员指导下使用。

## 没有被证明的内容

- 一般健康人补镁能够延长寿命；
- 所有睡眠不佳、抽筋或疲劳都由缺镁导致；
- 所有镁盐吸收、耐受性和临床作用相同；
- 平均血压下降可以直接等同于心血管事件减少。

## 适用条件

- 首先评估饮食来源：绿叶蔬菜、豆类、坚果、种子与全谷物；
- 记录元素镁，而不是只记录化合物总重量；
- 柠檬酸盐、氯化物、乳酸盐等通常比氧化镁更易吸收，但具体选择仍取决于目标和耐受性；
- 肾功能不全、长期使用质子泵抑制剂、利尿剂或出现持续腹泻时，需单独评估。

## 安全边界

- NIH ODS 给出的成人“来自补充剂和药物”的镁 UL 为每日 350 mg；食物天然含镁不计入该上限；
- 常见不良反应是腹泻、恶心和腹部绞痛；
- 肾功能受损时镁毒性风险升高；
- 镁可影响双膦酸盐、四环素和喹诺酮类抗生素的吸收，需要错开服用；
- 极高剂量可引起低血压、呼吸困难、心律失常甚至心搏骤停。

## Tier 判断

- 当前 Tier：**T2**
- 支持理由：必需营养素；缺乏风险、部分疾病情境及安全监测边界可以明确；
- 降级理由：一般健康人的常规补充临床获益有限，血压平均效应小且异质；
- 哪些新证据会改变判断：一般人群长期临床事件试验，或能可靠识别真正不足者并证明功能获益的策略试验。
