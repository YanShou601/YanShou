# 个人每日方案

> 2026-07-27 已制定 [亚精胺、麦角硫因、Ca-AKG、NAD⁺ 前体 12 周导入计划](frontier-four-rollout-2026.md)。四项状态为 `planned`，按阶段加入；在各自开始日期前不提前并入下方“执行中”时间表。

## 每日时间线

### 起床后

- **白水 500 ml**
- **桑葚汁 200 ml**
- **香蕉 1 根**（训练前 20–30 分钟吃）

### 训练前

- **跑步机热身**：4 倍速，快速走 20 分钟

### 力量训练（三天循环）

详见 [训练计划](training-plan.md)

- 第一天：胸 + 三头
- 第二天：背 + 二头
- 第三天：肩 + 腿
- 核心 + 腹部：隔天练（暂未开始）

### 补剂服用时间表（科学安排）

::: tip 核心原则
- **脂溶性**补剂（CoQ10、维生素 E、Omega-3、维生素 D3）必须**随含油脂的餐食**吃，否则吸收率很低
- **水溶性**补剂（B12、维生素 C、烟酰胺）空腹或随餐都行
- **B12 和烟酰胺**有轻微提神作用，**放早上**，别晚上吃
- **PS（磷脂酰丝氨酸）** 早上吃帮助白天认知；如果晚上吃可以帮助降低皮质醇、改善睡眠——两个时间都可以，选一个固定下来
- **肌酸**时间不重要，关键是**每天吃**让肌肉储备饱和；放早餐/训练后固定吃
- **镁**放晚上，帮助肌肉恢复和睡眠；与钙剂、抗生素错开 2 小时
- **训练前能量**：空腹一夜肝糖原消耗大半，训练前 20–30 分钟吃一根香蕉（快碳，训练中当场烧掉，不算糖摄入）；饿到头晕硬练会掉训练质量和肌肉，是更大的长寿损失
:::

#### 起床后（空腹）

| 补剂 | 用量 | 为什么这个时间 |
|---|---|---|
| 白水 | 500 ml | 补一夜的脱水，脱水本身就会让训练头晕 |
| 桑葚汁 | 200 ml | 花青素空腹吸收好 |
| **香蕉** | 1 根（~25 g 碳水） | 训练前 20–30 分钟的快碳燃料：运动中经胰岛素非依赖通道直接进肌肉烧掉，防头晕乏力；完整水果带纤维，不是"摄入糖" |
| **纳豆** | 1 盒（~45 g） | 植物蛋白 8–9g + 维生素 K2（天然最高来源）+ 亚精胺 + 益生菌 + 铁 + 镁。一种食物顶五样 |
| **甲钴胺（B12）** | 0.5 mg × 1 片 | 水溶性，空腹吸收好；有轻微提神作用，早上吃不影响睡眠 |

#### 训练后 + 早餐时（随餐，餐中需有油脂）

| 补剂 | 用量 | 为什么这个时间 |
|---|---|---|
| **CoQ10 + PQQ**（莱特维健） | 2 粒 | CoQ10 是脂溶性，必须随含油脂的饭吃才能吸收；PQQ 与 CoQ10 协同，一起吃；早上吃不会干扰睡眠 |
| **PS + 神经酸**（莱特维健） | 2 粒 | PS 早上吃支持白天认知和专注；随餐吃减少胃肠不适 |
| **Omega-3**（Life Extension） | 按标签（通常 2 粒） | EPA/DHA 是脂肪酸，必须随含油脂的餐食吃；早上吃一整天都有抗炎保护 |
| **若特兰德咀嚼片**（维C + E + 烟酰胺） | 按标签 | 维生素 E 是脂溶性，需要随餐；烟酰胺有轻微提神作用，放早上；维生素 C 随餐吃减少胃刺激 |
| **维生素 D3 + K2**（诺奥 NOW） | 1 粒（D3 1000 IU + K2 MK-4 45 μg） | D3 是脂溶性，必须随含油脂的餐食吃；放早上；与纳豆的天然 K2 叠加覆盖；1000 IU 是保守维持量，测完 25(OH)D 再评估 |
| **肌酸**（诺奥 NOW Sports） | 5 g（约 1½ 平茶匙，溶入饮品） | 时间不重要，关键是每天吃；随早餐固定下来最容易坚持；不需要冲击期，5 g/天 3–4 周自然饱和 |

#### 晚上

| 补剂 | 用量 | 说明 |
|---|---|---|
| **镁**（Doctor's Best 高吸收镁） | 2 片（200 mg 元素镁） | Albion TRAACS 螯合镁（甘氨酸+赖氨酸螯合），胃肠刺激小；晚上吃帮助肌肉恢复和睡眠；只用水送服，不算进食 |

| 食物 | 说明 |
|---|---|
| 完整猪肝一块 | 天然 B12 + 铁 + 维生素 A |

### 为什么这样安排？

`
起床（空腹）
  └─ 白水 500 ml → 补一夜脱水
  └─ 香蕉 1 根 → 训练前快碳，防肝糖原耗尽头晕
  └─ 桑葚汁 + B12 → 水溶性，空腹吸收最好，B12 提神开启一天

训练后 + 早餐（有油脂的饭）
  └─ CoQ10+PQQ → 脂溶性，没油脂吃了也白吃
  └─ PS+神经酸 → 支持白天认知
  └─ Omega-3 → 脂溶性，需要油脂帮助吸收
  └─ 维C+E+烟酰胺 → 维E脂溶性需要油脂，烟酰胺提神放早上
  └─ D3+K2 → D3 脂溶性，需要油脂帮助吸收，放早上
  └─ 肌酸 5 g → 时间不重要，跟着早餐固定吃最容易坚持

晚上
  └─ 不进食（睡前不进食原则）
  └─ 镁 200 mg → 帮助肌肉恢复和睡眠，用水送服不算进食
`

### ⚠️ 常见错误

| 错误 | 为什么错 |
|---|---|
| CoQ10 空腹吃 | 脂溶性，空腹吸收率极低，等于白吃 |
| Omega-3 空腹吃 | 同上，而且容易反胃、打鱼腥嗝 |
| D3 空腹吃 | 脂溶性，没有油脂吸收大打折扣 |
| B12 晚上吃 | 有轻微提神作用，可能影响入睡 |
| 肌酸想起来才吃 | 肌酸靠肌肉储备饱和起效，断断续续等于没吃 |
| 镁和钙片/抗生素同时吃 | 互相竞争吸收，需要错开 2 小时 |
| 空腹硬练到头晕 | 肝糖原已耗尽，训练质量差还掉肌肉；起床先 500 ml 水 + 训练前一根香蕉 |
| 训练前喝甜饮料"充能" | 液态添加糖才是长寿该戒的；要快碳吃香蕉，不要喝糖水 |
| 所有补剂睡前一把吃 | 脂溶性的没油脂吸收不了，B12/烟酰胺影响睡眠 |
| 买了不吃 | 最大的错误 |
