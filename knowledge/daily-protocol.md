# 个人每日方案

## 每日时间线

### 起床后

- **桑葚汁 200 ml**

### 训练前

- **跑步机热身**：4 倍速，快速走 20 分钟

### 力量训练（三天循环）

详见 [训练计划](training-plan.md)

- 第一天：胸 + 三头
- 第二天：背 + 二头
- 第三天：肩 + 腿
- 核心 + 腹部：隔天练（暂未开始）

### 补剂服用时间表（科学安排）

::: tip 核心原则
- **脂溶性**补剂（CoQ10、维生素 E、Omega-3）必须**随含油脂的餐食**吃，否则吸收率很低
- **水溶性**补剂（B12、维生素 C、烟酰胺）空腹或随餐都行
- **B12 和烟酰胺**有轻微提神作用，**放早上**，别晚上吃
- **PS（磷脂酰丝氨酸）** 早上吃帮助白天认知；如果晚上吃可以帮助降低皮质醇、改善睡眠——两个时间都可以，选一个固定下来
:::

#### 起床后（空腹）

| 补剂 | 用量 | 为什么这个时间 |
|---|---|---|
| 桑葚汁 | 200 ml | 花青素空腹吸收好 |
| **甲钴胺（B12）** | 0.5 mg × 1 片 | 水溶性，空腹吸收好；有轻微提神作用，早上吃不影响睡眠 |

#### 训练后 + 早餐时（随餐，餐中需有油脂）

| 补剂 | 用量 | 为什么这个时间 |
|---|---|---|
| **CoQ10 + PQQ**（莱特维健） | 2 粒 | CoQ10 是脂溶性，必须随含油脂的饭吃才能吸收；PQQ 与 CoQ10 协同，一起吃；早上吃不会干扰睡眠 |
| **PS + 神经酸**（莱特维健） | 2 粒 | PS 早上吃支持白天认知和专注；随餐吃减少胃肠不适 |
| **Omega-3**（Life Extension） | 按标签（通常 2 粒） | EPA/DHA 是脂肪酸，必须随含油脂的餐食吃；早上吃一整天都有抗炎保护 |
| **若特兰德咀嚼片**（维C + E + 烟酰胺） | 按标签 | 维生素 E 是脂溶性，需要随餐；烟酰胺有轻微提神作用，放早上；维生素 C 随餐吃减少胃刺激 |

#### 晚上

| 补剂 | 用量 | 说明 |
|---|---|---|
| （暂无） | — | 后续加入镁后放晚上吃 |

#### 每周六

| 食物 | 说明 |
|---|---|
| 完整猪肝一块 | 天然 B12 + 铁 + 维生素 A |

### 为什么这样安排？

`
起床（空腹）
  └─ 桑葚汁 + B12 → 水溶性，空腹吸收最好，B12 提神开启一天

训练后 + 早餐（有油脂的饭）
  └─ CoQ10+PQQ → 脂溶性，没油脂吃了也白吃
  └─ PS+神经酸 → 支持白天认知
  └─ Omega-3 → 脂溶性，需要油脂帮助吸收
  └─ 维C+E+烟酰胺 → 维E脂溶性需要油脂，烟酰胺提神放早上

晚上
  └─ 不进食（睡前不进食原则）
  └─ 后续加镁 → 帮助肌肉恢复和睡眠
`

### ⚠️ 常见错误

| 错误 | 为什么错 |
|---|---|
| CoQ10 空腹吃 | 脂溶性，空腹吸收率极低，等于白吃 |
| Omega-3 空腹吃 | 同上，而且容易反胃、打鱼腥嗝 |
| B12 晚上吃 | 有轻微提神作用，可能影响入睡 |
| 所有补剂睡前一把吃 | 脂溶性的没油脂吸收不了，B12/烟酰胺影响睡眠 |
| 买了不吃 | 最大的错误 |
